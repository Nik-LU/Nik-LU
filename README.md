# Никита Лушнов

Android-разработчик. Пишу приложения на Kotlin с упором на понятную архитектуру, предсказуемое управление состоянием и удобный UI.

## Проекты

- [FinanceTracker](https://github.com/Nik-LU/FinanceTracker) — offline-first приложение для управления личными финансами, аналитики и синхронизации данных.
- [Notes](https://github.com/Nik-LU/Notes) — приложение заметок на Jetpack Compose с Room, Hilt и Clean Architecture.
- [WeatherApp](https://github.com/Nik-LU/WeatherApp) — погодное приложение с MVI, Decompose, Dagger и Retrofit.
- [Terminal](https://github.com/Nik-LU/Terminal) — график котировок с кастомной отрисовкой через Compose Canvas.
- [Composition](https://github.com/Nik-LU/Composition) — Android-викторина на XML, Fragments и Navigation Component.

## Основной стек

Kotlin · Jetpack Compose · Coroutines · Flow · MVVM/MVI · Clean Architecture · Room · Retrofit · Hilt/Dagger
